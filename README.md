## 💻 How to Run Locally

### Option 1: Direct Browser Launch
- Double-click [`preview.bat`](preview.bat) or open [`imfa-care-group/index.html`](imfa-care-group/index.html) directly in any modern browser (Google Chrome, Edge, Firefox).

### Option 2: Local HTTP Server (Python)
```bash
python -m http.server 8080
```
Navigate to: [http://localhost:8080/imfa-care-group/](http://localhost:8080/imfa-care-group/)

## 📷 Updating Image Assets

To replace generic supporting images with your genuine company photographs:
1. Place your images in `imfa-care-group/assets/images/`.
2. Keep the existing filenames (`hero-distribution.jpg`, `about-trade.jpg`, `fmcg-products.jpg`, `pharma-products.jpg`, `interior-design.jpg`) or update the `src` attribute in `imfa-care-group/index.html`.
